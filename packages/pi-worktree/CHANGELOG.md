# @djoeyg/pi-worktree

## 0.2.0

### Minor Changes

- 9512667: Add pi-worktree: `/worktree <branch> [prompt]` forks the session into a git worktree and opens it in a tab inside pi, where its agent runs in parallel with the main session. Alt+W and Alt+1…9 switch tabs; `/worktree close|remove` stops a tab or removes its worktree.
